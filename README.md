# VK Видео для Roku TV

Неофициальное приложение (канал) VK Видео для телевизоров Roku: рекомендации «Для вас», «Тренды» и поиск по ВКонтакте с воспроизведением в 1080p. Написано на BrightScript + SceneGraph, ставится на телевизор в режиме разработчика (sideload).

Официального приложения ВКонтакте для Roku нет. По умолчанию телевизор ходит в ВК напрямую — в России этого достаточно.

## Возможности

- **Для вас** — персональные рекомендации вашего аккаунта (`catalog.getSection`), уже просмотренное скрыто.
- **Тренды** — раздел трендов VK Видео.
- **Поиск** — экранная клавиатура (RU / EN / цифры), подсказки ВК при наборе, история «Недавние», результаты обновляются на каждом символе. Можно печатать и диктовать с телефона через клавиатуру в мобильном приложении Roku.
- **Плеер** — HLS 1080p (минимум 720p), OK — пауза, ←/→ — перемотка на 10 с, своя панель с прогрессом.
- **Статистика** — просмотр засчитывается в ВК, время просмотра попадает в историю (как в официальном плеере).
- Под карточкой — просмотры и давность («3 дня назад»), OK на вкладке перезагружает её.

## Как это устроено

```
Roku TV ──────────────────────────────────> api.vk.com, CDN видео ВК, api.okcdn.ru
Roku TV ──> relay.py (необязательно) ──────^
```

| Файл | Что внутри |
|---|---|
| `source/main.brs` | точка входа; принимает токены из параметров запуска |
| `components/MainScene.xml/.brs` | весь интерфейс: вкладки, сетка, поиск, клавиатура, плеер, статистика |
| `components/ApiTask.xml` | HTTP-запросы к API ВК (Task, 3 попытки по 7 с) |
| `components/VideoItem.xml`, `KeyItem.xml`, `RecentItem.xml` | карточка видео, клавиша, строка истории |
| `relay.py` | необязательный релей на чистом Python: только домены ВК, секретный ключ в пути, Range, подмена HLS-плейлистов |
| `login.py` | получение токенов ВК и отправка их на телевизор |
| `deploy.sh` | сборка `vkroku.zip` и установка на телевизор |

Токены:
- **официальный токен VK Android** (вход по QR) — рекомендации, тренды, история, статистика;
- **токен Kate Mobile** — `video.search` (официальный токен отдаёт результаты поиска без ссылок на видео).

Оба хранятся только в реестре телевизора.

## Установка

1. **Режим разработчика на Roku.** На пульте: Home ×3, ↑ ×2, → ← → ← →. Включите его, задайте пароль и запомните IP телевизора.
2. **Сборка и установка:**
   ```bash
   DEV_PASS=<пароль> TV=<IP> ./deploy.sh install
   ```
3. **Вход:** `python3 login.py <IP телевизора>`. Подтвердите QR-ссылку на телефоне, затем войдите в Kate Mobile по второй ссылке и вставьте итоговый URL. Повторяйте после каждой переустановки: sideload стирает реестр.

## Если вы за границей: релей (необязательно)

За пределами России ВК часто отдаёт видео очень медленно (у нас из Бразилии было ~2 Мбит/с на соединение): 1080p не успевает грузиться, старт видео — 10–15 секунд. Roku OS не поддерживает VPN, поэтому помогает промежуточный сервер с хорошим каналом до ВК — например, VPS в Европе или в России. Через него идут и API, и видео (ссылки на видео ВК привязаны к IP, который их запросил).

С релеем приложение играет HLS: старт за 3–5 секунд, 1080p (не ниже 720p). Без релея — прямой mp4.

1. На сервере (нужен только Python 3, без зависимостей):
   ```bash
   RELAY_KEY=$(openssl rand -hex 12) PORT=8787 python3 relay.py
   ```
   Релей пропускает только домены ВК и только запросы с ключом в пути — это не открытый прокси.
2. Поставьте перед ним HTTPS (Caddy, Traefik, Coolify и т. п.) и **отключите gzip-сжатие** для этого сервиса, иначе видео тормозит.
3. Соберите приложение с релеем:
   ```bash
   RELAY=https://relay.example.com RELAY_KEY=<ключ> DEV_PASS=<пароль> TV=<IP> ./deploy.sh install
   ```

`deploy.sh` также умеет брать эти значения из Связки ключей macOS (`vk-roku-relay-url`, `vk-roku-relay-key`, `vk-roku-dev-installer`).

## Заметки для разработчиков и агентов

- Тестирование без пульта: ECP на порту 8060 (`POST /keypress/Right`, `/keypress/Lit_%D0%BA` — ввод символа), консоль отладки — `nc <IP> 8085`, скриншот — `/plugin_inspect` на порту 80.
- Узел `Video` перехватывает нажатия даже с `enableUI=false` — фокус держит группа `osd`. `pos` и `try` — зарезервированные слова.
- Roku зацикливается на мастер-плейлистах ВК, поэтому релей отдаёт 302 на вариант 1080p. URI с вторым `://` в пути Roku не понимает — плейлисты идут в виде `/KEY/h/host/path`, сегменты остаются относительными.
- Около 1 из 9 новых соединений сервер→ВК зависает на рукопожатии — в релее таймаут подключения 1,5 с и 5 повторов.
- Время просмотра в ВК считается только через статистику плеера OK.ru: `video.getStatsToken` → `auth.anonymLogin` на `api.okcdn.ru/fb.do` → `log.externalLog` с элементами `wr` (см. `viewStart`/`flushRanges` в `MainScene.brs`). Счётчик просмотров — `video.getHashes` → `video.incViewCounter`.
- `catalog.getVideoSearch` с `q`, но без `show_suggests=1`, **добавляет запрос в историю поиска** пользователя. Подсказки — с `show_suggests=1&input_method=keyboard`.
- В системном шрифте Roku нет многих символов (эмодзи и т. п.): `clean()` оставляет только поддерживаемые диапазоны.

## Ограничения

- Не в Roku Channel Store: используются ключи сторонних клиентов ВК и неофициальные методы API, такое не пройдёт сертификацию Roku и противоречит правилам ВК. Только sideload, одно dev-приложение на телевизор.
- Голосовой поиск пульта Roku не распознаёт русский — используйте клавиатуру телефона.

Проект не связан с VK и Roku. Используйте на свой страх и риск.
